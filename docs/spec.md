
# Order Summary Screen Specification

## 1. Inputs
- Receive an order total from the order data.
- Receive the item name and quantity.

## 2. Outputs
- Display the order item name.
- Display the item quantity.
- Display the total price in RM.

## 3. Rules
- The order total must be calculated using the order data.
- The total price must be displayed with two decimal places.
- The screen must include a Back button.

## 4. Out of Scope
- No payment gateway or online payment.
- No user login or registration.

## 5. Check
- The screen must display the correct item name and quantity.
- The screen must display the expected total of RM25.00.
- The Back button must return to the previous screen.
